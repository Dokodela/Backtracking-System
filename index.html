2. WHILE NSL ≠ [ ] DO:

IF CS has unvisited children (not in SL or DE) THEN:
add children to head of NSL; CS = car(NSL); add CS to SL;
ELSE (Dead-End! CS has no children):
WHILE SL ≠ [ ] and CS = car(SL) DO:
add CS to DE; remove CS from SL; remove CS from NSL;
CS = car(NSL); add CS to SL;
