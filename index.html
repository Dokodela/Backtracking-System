Luger Backtracking Search Formal Algorithm

// Initialization SL := [Start];  NSL := [Start];  DE := [ ];  CS := Start;

// Main Loop while NSL is not empty do
  if CS = Goal then return SL; // Success! Path found
  if CS has children not in (DE ∪ SL ∪ NSL) then
    add children to the head of NSL;
    CS := head of NSL;
    add CS to head of SL;
  else
    // Dead End encountered! Backtrack
    remove CS from NSL;
    add CS to DE;
    remove CS from SL;
    CS := head of SL (or parent on active path);
return FAIL;
State Definitions
  • CS: Current state under evaluation.
  • SL: State list (the sequence from start to CS).
  • NSL: New state list (frontier / candidate stack).
  • DE: Dead ends (pruned subtrees).
Textbook Convention (Figure 3.14)

In George Luger's canonical trace, when children are generated (e.g. B, C, D for node A), they are placed at the front of NSL in left-to-right order, and the leftmost is immediately selected as next CS and pushed onto SL.
